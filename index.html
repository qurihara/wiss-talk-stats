WISS 登壇発表の第一著者の統計（1993–2025）

日本ソフトウェア科学会の「インタラクティブシステムとソフトウェアに関するワークショップ」（WISS）について、第1回（1993年）から第33回（2025年）までの登壇発表を全件集め、第一著者ごとの登壇回数を集計した調査である。

調査と集計：栗原一貴（津田塾大学）　｜　スライド版　｜　データとスクリプト（GitHub）

暫定版である。 WISS2026（第34回）のプログラムが公開されたあとに2026年分を加え、確定版とする予定である。

年ごとの推移

著者全員で見た分析

第一著者だけでなく、登壇発表の著者として名前を連ねた人を全員数えた。1994年以降は著者全員を数え、1993年は共著者が分からないので、分かっている第一著者だけを数えた。

  • 登壇発表に著者として関わった人は 976人 である。
  • 最も多くの登壇発表に関わったのは 五十嵐健夫さんの80件 で、2位の小池英樹さん（41件）を大きく上回る。五十嵐健夫さんの80件のうち57件は最終著者である。
  • 第一著者としての回数と、著者として関わった数は、別の人を浮かび上がらせる。第一著者の回数が少なくても、共著者として数十件に関わった人がいる。研究室や研究グループを率いて、学生や若手の研究者の発表を支えてきた人たちと考えられる。
  • 登壇発表1件あたりの著者の数は、1990年代の平均の約2.4人から、2020年代の平均の約3.5人に増えた。

発表速度

登壇回数の多さは、活動してきた年数の長さにも左右される。そこで、年数あたりの登壇の多さを表す指標として「発表速度」を定めた。

  • デビュー年：第一著者として初めて登壇した年。
  • 経過年数：デビュー年を1年目として、集計の最後の年（2025年）まで数えた年数。
  • 発表速度：第一著者としての登壇回数を経過年数で割った値（回/年）。

発表速度の偏りと、その補正

発表速度をそのまま比べると、デビューが最近の人ほど値が高く出る。経過年数が短いと少ない回数でも値が大きく振れること、デビュー年には必ず1回が入っていることが、その原因である。そこで、登壇回数がポアソン分布に従うと考え、発表速度の95%信頼区間の下限で並べた（Garwood の正確な信頼区間）。経過年数が短く回数が少ない人ほど区間が広がり、下限が下がる。この方法なら足切りが要らないので、第一著者471人の全員を並べた。

経緯

  1. 2011年に、1994年から2011年までの一覧を作った。 栗原一貴が、WISS のウェブサイトのプログラムと紙の予稿集から、登壇発表410件の題名と著者（第4著者まで）を Microsoft Access のデータベースにまとめた。1997年のウェブのプログラムは著者の大半が姓だけで書かれているので、この年の姓名は紙の予稿集で補ったと考えられる。
  2. 2026年10月に、全回を調べ直した。 栗原一貴の WISS2026 の登壇発表が何回目にあたるかを確かめる目的で始め、全員の順位表を作る調査に広げた。wiss.org に残る各年のプログラムと予稿集の目次を取得し、生成AI（Anthropic の Claude Code）に年代ごとに分けて一覧の表を作らせた。表は、取得したページの本文と全件を機械で照合して確かめた。
  3. 2011年のデータベースと突き合わせた。 1994年から2011年までの410件を、題名で対応づけて第一著者を照合した。食い違いは、旧姓による表記の違いが1件と、データベースで名前が途中で切れていたものが2件だけであった。データベースに漏れていた登壇発表が3件見つかった。
  4. 1993年（第1回）を再構成した。 1993年だけは発表の一覧のページが作られておらず、出版社（近代科学社）の書籍のページに題名38件だけが残っている。CiNii の引用の書誌、学会誌「コンピュータソフトウェア」11巻6号（1994年）の特集への再録、本人の researchmap、同じ著者の後の論文から、24件の第一著者を補った。残る14件は分かっていない。

方法

  • 数えたもの：論文を伴う口頭発表（登壇発表）の第一著者。ロング発表、ショート発表、議論枠の発表を含む。
  • 数えていないもの：デモ・ポスター発表、招待講演、国際学会招待発表、ロングティザー発表、WISS Challenge、WISS Design。
  • 情報源：1993年は近代科学社の書籍のページの目次、1994年から2004年は wiss.org の各年のプログラム、2005年以降は wiss.org の各年の予稿集の目次とプログラム。
  • 名前の表記の揺れ：空白と異体字をそろえ、旧姓と字体の違いは対応表で同一人物として扱った。上位の人については、別の表記で数え漏れていないことを目で確かめた。

この調査の限界

  • 1993年の14件は第一著者が分からない。紙の予稿集で確かめれば埋められる。
  • 1993年の第一著者のうち2件は、同じ時期に同じ主題の論文を書いていることからの推定である。
  • 同じ人が姓を変えた場合、対応表に載せた人だけを同一人物として扱っている。英字の名前は照合していない。
  • デモ・ポスター発表は、一覧が残っている年だけを数えた。

データと再現の手順

集計に使った表、スクリプト、2011年のデータベースは、すべて GitHub のリポジトリにある。元のページを取得し直して、年ごとの表を1から作り直す手順も用意した（再現と発展のための手順）。スクリプトは MIT ライセンス、表と図と文章は CC BY 4.0 で提供する。
