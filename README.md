# WISS 登壇発表の第一著者（すなわちおそらく発表者）の統計（1993–2026）

日本ソフトウェア科学会の「インタラクティブシステムとソフトウェアに関するワークショップ」（WISS）について、第1回（1993年）から第34回（2026年）までの登壇発表を全件集め、第一著者ごとの登壇回数を集計した調査である。

調査と集計：栗原一貴（津田塾大学）　｜　2026年11月12日時点　｜　版 1.0.1（確定版）　｜　[変更履歴](CHANGELOG.md)

- **HTML 版**：https://unryu.org/wiss-talk-stats/
- **スライド版**：https://unryu.org/wiss-talk-stats/slides.html （← → キーで移動）

## 調査の結果の概要

- 1993年から2026年までの34回で、登壇発表は **765件** あった。そのうち751件の第一著者が分かっており、第一著者は **498人** である。
- 第一著者の **80%（401人）は、登壇発表が1回だけ** である。2回以上登壇した97人の発表が、全体の47%を占める。
- 最も多く登壇したのは、**暦本純一さんと五十嵐健夫さんの14回** である。次いで綾塚祐二さんの11回、竹川佳成さんの10回、栗原一貴さんの10回、増井俊之さんの9回が続く。
- 各年の登壇発表のうち、第一著者が WISS で初めて登壇する発表の割合は、平均で67%である。2020年以降は70%から92%である。
- 登壇発表は毎年15件から38件である。一方、デモ・ポスター発表は2020年以降に大きく増え、2025年には143件になった。
- 登壇回数をデビューからの経過年数で割った「発表速度」を、95%信頼区間の下限で並べると、SECHAYK Yotamさん、五十嵐健夫さん、小林直生さんの順になる（[発表速度](#発表速度)）。
- 著者全員で数えると、登壇発表に関わった人は1033人である。最も多くの登壇発表に関わったのは五十嵐健夫さんの81件である（[著者全員で見た分析](#著者全員で見た分析)）。

## 著者全員で見た分析

第一著者だけでなく、登壇発表の著者として名前を連ねた人を全員数えた。1994年以降は著者全員を数え、1993年は共著者が分からないので、分かっている第一著者だけを数えた。

- 登壇発表に著者として関わった人は **1033人** である。
- 最も多くの登壇発表に関わったのは **五十嵐健夫さんの81件** で、2位の小池英樹さん（41件）を大きく上回る。五十嵐健夫さんの81件のうち58件は最終著者である。
- 第一著者としての回数と、著者として関わった数は、別の人を浮かび上がらせる。第一著者の回数が少なくても、共著者として数十件に関わった人がいる。研究室や研究グループを率いて、学生や若手の研究者の発表を支えてきた人たちと考えられる。
- 登壇発表1件あたりの著者の数は、1990年代の平均の約2.4人から、2020年代の平均の約3.5人に増えた。

## 発表速度

登壇回数の多さは、活動してきた年数の長さにも左右される。そこで、年数あたりの登壇の多さを表す指標として「発表速度」を定めた。

- **デビュー年**：第一著者として初めて登壇した年。
- **経過年数**：デビュー年を1年目として、集計の最後の年（2026年）まで数えた年数。例えば2004年のデビューなら23年である。
- **発表速度**：第一著者としての登壇回数を経過年数で割った値（回/年）。1.0 なら毎年1回登壇していることになる。

### 発表速度の偏りと、その補正

発表速度をそのまま比べると、デビューが最近の人ほど値が高く出る。経過年数が短いと、少ない回数でも割り算の値が大きく振れること、デビュー年は登壇した年として決まるので、1年目には必ず1回が入っていることが、その原因である。

そこで、登壇回数がポアソン分布に従うと考え、発表速度の **95%信頼区間の下限** で並べた（Garwood の正確な信頼区間）。経過年数が短く回数が少ない人ほど区間が広がり、下限が下がる。評価の件数が少ない商品を、平均点ではなく信頼区間の下限で並べるのと同じ考え方である。この方法なら登壇回数の足切りが要らないので、第一著者498人の全員を同じ表で並べた。

## 経緯

1. **2011年に、1994年から2011年までの一覧を作った。** 栗原一貴が、WISS のウェブサイトのプログラムと紙の予稿集から、登壇発表410件の題名と著者（第4著者まで）を Microsoft Access のデータベースにまとめた（[legacy/](legacy/)）。1997年のウェブのプログラムは著者の大半が姓だけで書かれているので、この年の姓名は紙の予稿集で補ったと考えられる。1997年に5人目の著者がいる2件は、5人目をウェブの姓から同じ年の姓名に引き当てて足した。
2. **2026年10月に、1993年から2025年までの33回を調べ直した。** 栗原一貴の WISS2026 の登壇発表が何回目にあたるかを確かめる目的で始め、全員の順位表を作る調査に広げた。wiss.org に残る各年のプログラムと予稿集の目次を取得し、生成AI（Anthropic の Claude Code）に年代ごとに分けて一覧の表を作らせた。表は、取得したページの本文と全件を機械で照合して確かめた。
3. **2011年のデータベースと突き合わせた。** 1994年から2011年までの410件を、題名で対応づけて第一著者を照合した。食い違いは、旧姓による表記の違いが1件と、データベースで名前が途中で切れていたものが2件だけであった。データベースに漏れていた登壇発表が3件見つかった（2002年、2003年、2004年に1件ずつ）。
4. **1993年（第1回）を再構成した。** 1993年だけは発表の一覧のページが作られておらず、出版社（近代科学社）の書籍のページに題名38件だけが残っている。CiNii の引用の書誌、学会誌「コンピュータソフトウェア」11巻6号（1994年）の特集「インタラクティブシステムとソフトウェア」への再録、本人の researchmap、同じ著者の後の論文から、24件の第一著者を補った。残る14件は分かっていない。

5. **2026年11月に、WISS2026（第34回）を加えた。** 2026年11月5日に、栗原一貴が参加者として受け取った仮プログラムの PDF から、登壇発表と国際学会招待発表の題名と著者を取り出した（[pipeline/parse_wiss2026_pdf.py](pipeline/parse_wiss2026_pdf.py)）。2026年11月12日に公式のプログラムが [wiss.org](https://www.wiss.org/WISS2026/program.html) で公開されたので、表をこちらから作り直した（[pipeline/parse_wiss2026_html.py](pipeline/parse_wiss2026_html.py)）。仮プログラムとの照合では、登壇発表35件の番号、順序、第一著者はすべて一致し、違いは題名の中の空白3件と、仮プログラムの表で取りこぼしていた国際学会招待発表1件の共著者だけであった。


## 方法

### 情報源

| 年 | 情報源 |
|---|---|
| 1993 | 近代科学社の書籍『インタラクティブシステムとソフトウェアI』のページ（Internet Archive の保存版）の目次。著者は上記の方法で補った |
| 1994–2004 | wiss.org の各年のプログラムのページ。1997年の姓名は2011年のデータベースで補った |
| 2005–2025 | wiss.org の各年の予稿集の目次と、ロング・ショートの区別のためのプログラムのページ |
| 2026 | wiss.org の公式のプログラムのページ（2026年11月12日に公開） |


### 数え方

- **数えたもの**：論文を伴う口頭発表（登壇発表）の第一著者。ロング発表、ショート発表、議論枠の発表を含む。
- **数えていないもの**：デモ・ポスター発表、招待講演、国際学会招待発表、ロングティザー発表（登壇発表として採択されなかった論文の短い紹介）、WISS Challenge、WISS Design。招待講演と国際学会招待発表は合わせて54件あり、表には区分を付けて残してある。
- **名前の表記の揺れ**：空白と異体字をそろえ、旧姓と字体の違いは対応表で同一人物として扱った（[rank.py](rank.py)）。上位の人については、別の表記で数え漏れていないことを目で確かめた。英字の名前は、上位に関わらないので照合していない。


### 1993年の第一著者の根拠

[data/1993.tsv](data/1993.tsv) の「根拠」の列に、次の3段階で根拠を書いた。

- **確定（16件）**：引用の書誌が複数ある、学会誌の特集に再録されている、または本人の researchmap に登録されている。
- **有力（6件）**：同じ人の、ほぼ同じ題名の後の論文がある。
- **推定（2件）**：同じ時期に同じ主題の論文を書いている。


## この調査の限界

- 1993年の14件は第一著者が分からない。紙の予稿集で確かめれば埋められる。上位の人の回数が変わる見込みは小さいが、1993年から登壇している人（暦本純一さん、綾塚祐二さん、増井俊之さん、原田康徳さんなど）の回数は増える可能性がある。
- 1993年の暦本純一さんの1回を除くと、五十嵐健夫さんが単独で最多になる。1993年の暦本さんの発表（InformationCube）は、学会誌への再録で確かめられている。
- ロング発表とショート発表の区別は、年によっては発表時間の長さから判断した。この区別は回数の集計には影響しない。
- 同じ人が姓を変えた場合、対応表に載せた人だけを同一人物として扱っている。
- 2026年は、会期の前に公開された公式のプログラム（2026年11月12日時点）に基づく。そのあとの発表の取り下げや題名の変更は反映されていない。012 の題名は、プログラムでも「開催1週間前に公開予定」となっている。2026年のデモ・ポスター発表は入れていない。

## 再現と発展のための手順

集計に使った表、スクリプト、2011年のデータベースは、すべてこのリポジトリに入っている。取得した元のページ（wiss.org のプログラムと予稿集の目次、2026年のプログラムの PDF）だけは、論文の概要の全文を含むので入れていない。その代わりに、元のページを取得し直して、年ごとの表を1から作り直す手順を用意した。Python 3 と matplotlib があれば動く。

1. `python3 pipeline/fetch_raw.py` … 1993年から2026年の元のページ53件を wiss.org と Internet Archive から `raw/` に取得する。URL と、取得したとき（1993年から2025年は2026年10月22日、2026年は2026年11月12日）の SHA-256 は [pipeline/sources.json](pipeline/sources.json) にある。当時から中身が変わったページがあれば表示する。
2. `python3 pipeline/prepare.py` … 文字コードを UTF-8 にそろえた写しと、文字だけの写しを作る。古いページは文字コードがまちまちなので、ファイルごとに指定してある。
3. `python3 pipeline/extract.py` … 年代ごとの抜き出しのスクリプト（[extraction/](extraction/)）を動かして年ごとの表を `build/WORK/out/` に作り、公開している `data/` と1件ずつ照合する。
4. `python3 rank.py`、`python3 make_figures.py`、`python3 build_site.py`、`python3 build_readme.py` … 順位表、図と数値、HTML 版とスライド版、この README を作る。

2026年の表（`data/2026.tsv`）は、手順3の中で `pipeline/parse_wiss2026_html.py` が公式のプログラムのページから作る。仮プログラムの PDF から表を作ったスクリプト（`pipeline/parse_wiss2026_pdf.py`）は、記録として残してある。

2026年10月22日に、元のページを持たない空のフォルダで手順1から4を通して動かし、1993年から2025年の33年分の表、順位表、図の数値、2つのページが、公開しているものと一致することを確かめた。2026年11月12日には、手順3で2026年を含む34年分の表が `data/` と一致することを確かめた。

この調査を発展させるときの入口は、次のとおりである。

- **別の数え方を試す**：`data/<年>.tsv` の `kind` 列に、デモ、招待講演、国際学会招待発表なども区分を付けて残してある。`rank.py` の `COUNTED` を変えれば、数える範囲を変えられる。
- **名前の表記の揺れを直す**：`rank.py` の `ALIASES` に、同一人物の別の表記を足す。
- **1993年を埋める**：`fill1993.py` の対応表に、第一著者と根拠を足す。
- **新しい年を足す**：`data/<年>.tsv` を同じ列で作り、手順4を動かす。


## 作り直す手順

1. 新しい年の `data/<年>.tsv` を同じ列で作る。
2. `python3 rank.py`、`python3 make_figures.py`、`python3 build_site.py`、`python3 build_readme.py` を順に動かす。
3. `VERSION` の番号を上げ、`CHANGELOG.md` に変更を書く。
